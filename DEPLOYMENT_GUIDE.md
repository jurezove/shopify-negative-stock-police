# Deployment Guide for Shopify Negative Stock Police

This guide walks you through deploying your Shopify inventory monitoring service to Railway and configuring the necessary webhooks.

## Prerequisites Checklist

Before you begin, ensure you have:

- [ ] Shopify Admin API Access Token (with `read_inventory` and `read_products` scopes)
- [ ] Slack Webhook URL
- [ ] Railway account (sign up at https://railway.app)
- [ ] GitHub repository (already created at https://github.com/jurezove/shopify-negative-stock-police)

## Step 1: Deploy to Railway

### Option A: Deploy from GitHub (Recommended)

1. **Log in to Railway**
   - Go to https://railway.app
   - Sign in with your GitHub account

2. **Create New Project**
   - Click **"New Project"**
   - Select **"Deploy from GitHub repo"**
   - Choose the repository: `jurezove/shopify-negative-stock-police`

3. **Configure Environment Variables**
   
   In the Railway dashboard, go to the **Variables** tab and add:

   | Variable Name | Value | Example |
   |--------------|-------|---------|
   | `SHOPIFY_STORE_DOMAIN` | Your Shopify store domain | `yoursoultime.myshopify.com` |
   | `SHOPIFY_ADMIN_API_TOKEN` | Your Admin API access token | `shpat_xxxxxxxxxxxxx` |
   | `SHOPIFY_WEBHOOK_SECRET` | Webhook signing secret (get this in Step 2) | `xxxxxxxxxxxxx` |
   | `SLACK_WEBHOOK_URL` | Your Slack webhook URL | `https://hooks.slack.com/services/...` |
   | `PORT` | Server port | `3000` |

4. **Deploy**
   - Railway will automatically deploy your application
   - Wait for the deployment to complete (usually 1-2 minutes)

5. **Get Your Deployment URL**
   - Go to the **Settings** tab
   - Under **Domains**, click **"Generate Domain"**
   - Copy your Railway URL (e.g., `https://shopify-negative-stock-police-production.up.railway.app`)

### Option B: Deploy with Railway CLI

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Link to project (or create new)
railway link

# Set environment variables
railway variables set SHOPIFY_STORE_DOMAIN=yoursoultime.myshopify.com
railway variables set SHOPIFY_ADMIN_API_TOKEN=your_token_here
railway variables set SLACK_WEBHOOK_URL=your_webhook_url_here
railway variables set PORT=3000

# Deploy
railway up
```

## Step 2: Configure Shopify Webhook

Now that your service is deployed, you need to configure Shopify to send webhooks to it.

### Get Shopify Admin API Token (if you haven't already)

1. Go to your Shopify Admin: `https://yoursoultime.myshopify.com/admin`
2. Navigate to **Settings** → **Apps and sales channels** → **Develop apps**
3. Click on your custom app (or create a new one)
4. Go to **"Configure Admin API scopes"**
5. Enable:
   - ✅ `read_inventory`
   - ✅ `read_products`
6. Click **"Save"** then **"Install app"**
7. Copy the **Admin API Access Token**

### Create the Webhook Subscription

You have two options to create the webhook:

#### Option A: Using Shopify Admin UI

1. In your custom app, go to the **"API credentials"** tab
2. Scroll down to **"Webhooks"** section
3. Click **"Create webhook subscription"**
4. Configure:
   - **Event**: Select `inventory_levels/update`
   - **Format**: JSON
   - **URL**: `https://your-railway-url.railway.app/webhooks/inventory-update`
   - **API version**: `2024-01` (or latest stable)
5. Click **"Save"**
6. **Copy the Webhook Signing Secret** that appears
7. Go back to Railway and add/update the `SHOPIFY_WEBHOOK_SECRET` environment variable

#### Option B: Using GraphQL Admin API

You can also create the webhook programmatically using the Shopify Admin GraphQL API:

```graphql
mutation {
  webhookSubscriptionCreate(
    topic: INVENTORY_LEVELS_UPDATE
    webhookSubscription: {
      format: JSON
      callbackUrl: "https://your-railway-url.railway.app/webhooks/inventory-update"
    }
  ) {
    webhookSubscription {
      id
      endpoint {
        __typename
        ... on WebhookHttpEndpoint {
          callbackUrl
        }
      }
    }
    userErrors {
      field
      message
    }
  }
}
```

**Note:** The webhook signing secret is automatically generated by Shopify. You can find it in the webhook details in your Shopify Admin.

## Step 3: Configure Slack Webhook

If you haven't already set up your Slack webhook:

1. Go to https://api.slack.com/apps
2. Click **"Create New App"** → **"From scratch"**
3. Name it "Inventory Alerts" and select your workspace
4. In the left sidebar, click **"Incoming Webhooks"**
5. Toggle **"Activate Incoming Webhooks"** to **ON**
6. Click **"Add New Webhook to Workspace"**
7. Select the channel where you want to receive alerts
8. Copy the **Webhook URL**
9. Add it to Railway as the `SLACK_WEBHOOK_URL` environment variable

## Troubleshooting

### Webhooks not being received

**Check Railway logs:**
- Are there any incoming requests?
- If not, verify the webhook URL in Shopify matches your Railway URL exactly

**Verify webhook in Shopify:**
- Go to your custom app → API credentials → Webhooks
- Check that the webhook is active and the URL is correct
- Look for any error messages or failed deliveries

### Signature verification failing

**Error:** `Unauthorized: Invalid signature`

**Solution:**
- Ensure `SHOPIFY_WEBHOOK_SECRET` in Railway matches the secret from Shopify
- The secret is shown when you create the webhook in Shopify
- You can find it in: Custom App → API credentials → Webhooks → Click on your webhook

### Slack notifications not sending

**Check Railway logs for errors:**
- Look for "Failed to send Slack notification" messages

**Verify Slack webhook URL:**
- Test it manually with curl:
  ```bash
  curl -X POST -H 'Content-Type: application/json' \
    -d '{"text":"Test from Shopify Stock Police"}' \
    YOUR_SLACK_WEBHOOK_URL
  ```
- If this fails, regenerate the webhook URL in Slack

### Product details not showing

**Error:** GraphQL errors in logs

**Solution:**
- Verify `SHOPIFY_ADMIN_API_TOKEN` has the `read_products` scope
- Check that the token is still valid (tokens can expire or be revoked)
- Ensure `SHOPIFY_STORE_DOMAIN` is correct (should be `yoursoultime.myshopify.com`)

### Service keeps restarting

**Check Railway logs for errors:**
- Look for any startup errors
- Verify all required environment variables are set
- Check that Node.js version is compatible (requires Node 18+)


### Environment Variable Updates

If you need to update environment variables:
1. Go to Railway dashboard
2. Click **Variables** tab
3. Edit or add variables
4. The service will automatically restart with new values

## Security Best Practices

1. **Never commit `.env` files** - They're already in `.gitignore`
2. **Rotate tokens regularly** - Update Shopify and Slack tokens periodically
3. **Monitor webhook activity** - Check Railway logs for suspicious activity
4. **Use HTTPS only** - Railway provides HTTPS by default
5. **Keep dependencies updated** - Run `npm update` regularly
